# TXT 阅读器 MVP 技术方案

## 1. 目标与范围

本方案对应[产品设计](product-design.md)，目标是在 macOS 上实现一个可运行的 TXT 阅读器参考版本，并作为逐步学习桌面应用开发的项目。

MVP 只包含 TXT 导入、书架、阅读、字号调整和阅读位置恢复。暂不加入 EPUB、章节目录、书签、主题切换、云同步、批注和全文搜索。

## 2. 技术选型

- **语言：C++**。与当前学习方向一致，可在项目中练习类、对象生命周期、标准库、文件处理和错误处理。
- **桌面框架：Qt 6 Widgets**。Qt 提供窗口、控件、文件选择窗口和事件机制；Widgets 适合用 C++ 直接搭建桌面界面。Qt 官方也提供了使用 C++/Widgets 制作记事本的入门教程，可作为学习参考：[Getting Started Programming with Qt Widgets](https://doc.qt.io/qt-6/widgets-getting-started.html)。
- **构建：CMake**。使用 Qt 6 的 CMake 集成管理目标、源文件和测试，方便理解编译与链接过程。
- **持久化：JSON 文件**。书籍元数据和阅读位置写入一个应用私有目录中的 JSON 文件；MVP 数据量很小，先不引入数据库。
- **测试：Qt Test + CTest**。为数据读写和进度恢复等可独立验证的逻辑编写小型测试；同时手动检查完整阅读流程。

## 3. 简单结构

保持少量模块，避免为了未来功能提前搭建复杂架构：

- **MainWindow**：主窗口和页面切换，展示书架或阅读页，连接用户操作与应用逻辑。
- **ReaderWidget**：显示纯文本，支持滚动和字号调整，并提供当前位置。
- **LibraryStore**：负责导入 TXT、管理应用内副本，以及读写书架和阅读进度数据。
- **Book**：表示一本书的最小信息：唯一 ID、书名、应用内文件名、阅读位置和最近阅读时间。

模块关系：

```text
用户操作
   ↓
MainWindow ─── ReaderWidget
   │                │
   └──── LibraryStore
              ├── 应用数据目录中的 TXT 副本
              └── library.json
```

## 4. 文件和数据

应用数据存放在 Qt 提供的应用专属数据目录下（`QStandardPaths::AppDataLocation`），目录中包含书籍副本和 `library.json`。导入时用文件选择窗口选择 TXT，将内容复制到应用目录并使用书籍 ID 命名；不依赖原文件路径，这样原文件被移动或删除后仍可阅读。

`library.json` 保存书名、应用内文件名、阅读位置和最近阅读时间。阅读位置以文本中的字符偏移量表示；打开书籍时跳转到该位置，滚动或离开阅读页时自动保存。字号属于阅读偏好，可以保存在 Qt 的应用设置中。

首版按 UTF-8 文本读取。TXT 编码并不统一，其他编码的自动识别暂不纳入 MVP；导入失败时应明确提示先用文本编辑器另存为 UTF-8（尤其是 GBK/GB18030），不能静默丢弃内容。

JSON 更新使用临时文件后原子替换，避免程序退出时留下半写入的数据。每次保存进度都写文件可能过于频繁，可以在滚动停止一小段时间后保存，并在切换书籍或关闭窗口时再保存一次。

## 5. 核心交互流程

1. **导入**：用户选择 TXT → 校验并读取 → 复制到应用数据目录 → 更新书架数据 → 刷新书架。
2. **阅读**：用户在书架选书 → 读取应用内副本 → 显示文本 → 根据保存的偏移量恢复位置。
3. **调整字号**：字号按钮修改阅读控件字体 → 记录应用偏好。
4. **保存进度**：滚动停止、切换书籍或关闭窗口时，读取当前可见位置并更新该书记录。

## 6. 建议实现顺序

每一步都保持应用可构建、可运行，并先理解当前部分再继续：

1. 创建 Qt Widgets + CMake 项目，运行一个空窗口。
2. 做出书架和阅读页之间的基本界面切换，并显示一段固定文本。
3. 接入 TXT 文件选择、读取和应用目录副本。
4. 保存书架元数据，退出重启后仍能看到已导入书籍。
5. 加入字号调整和阅读位置的自动保存、恢复。
6. 补齐异常处理与测试，按验收标准手动走完导入、阅读、重启恢复流程。

## 7. 验证方式

- **自动测试**：验证书架 JSON 的保存/重新加载、导入副本的存在，以及阅读偏移量保存和恢复；由 CTest 运行。
- **手动验收**：导入 UTF-8 TXT，确认书架显示；打开并滚动；调整字号；退出并重新启动；再次打开同一本书，确认位置恢复。再检查取消文件选择、空文件和找不到书籍副本时的提示。
- **每次改动**：更新相关测试，运行测试和必要的手动验证，通过后创建简短 Git commit。

## 8. 学习协作约定

先完成一个最小、完整、可运行的 MVP 参考实现，再按上述功能顺序拆解讲解。每次说明代码职责、关键概念和数据流；优先给出提示，让我尝试理解或复现。每天按约一小时的学习节奏拆分任务，不扩展到 MVP 之外。
